SUMRUDRA FINANCE EMI CALCULATOR - ANDROID PROJECT

This project wraps the latest Sumrudra Finance calculator HTML into an offline Android app.

Included calculators:
1. Eligibility Calculator
2. Basic EMI Calculator
3. Loan Affordability Calculator
4. Home Loan Calculator
5. Compare Your Loan

App name:
Sumrudra Finance EMI Calculator

Package:
com.sumrudra.finance.emicalculator

The project is also configured with GitHub Actions:
.github/workflows/build-apk.yml

On GitHub:
1. Upload this project to a repository.
2. Open Actions.
3. Select "Build Sumrudra APK".
4. Click "Run workflow".
5. Download the generated APK from the workflow's Artifacts section.

The APK is not signed for Play Store release; a release keystore/signing step is required before publishing.
